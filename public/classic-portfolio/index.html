How I work

A clear path from idea to prototype.

I keep the signal chain simple, make each stage testable, and improve it through hands-on iteration.

01 / DEFINE

Understand the signal

What needs to be measured, and what should happen in response?

02 / PROTOTYPE

Wire the path

Pick the board, sensor and actuator. Build the smallest working version first.

03 / TUNE

Test and adjust

Diagnose faults, tune thresholds and make the behaviour repeatable.

04 / SHARE

Document the build

Leave behind clear notes, wiring logic and next steps anyone can follow.
